# FleetPulse – Real-Time & Historical Vehicle Fleet Analytics on AWS

FleetPulse is a cloud-native vehicle fleet analytics platform built using the **Lambda Architecture**. The system processes real-time vehicle telemetry while simultaneously maintaining a complete historical record for analytics and reporting.

The solution combines AWS managed services to provide low-latency monitoring, scalable processing, and historical insights through a single dashboard.

## Data Flow

1. Vehicle telemetry is generated by the producer.
2. Data is streamed into Amazon Kinesis.
3. AWS Lambda processes live events.
4. Aggregated metrics are stored in DynamoDB.
5. Firehose archives raw data into Amazon S3.
6. Apache Spark processes historical data.
7. Athena queries batch results.
8. Flask combines live and historical analytics into one dashboard.
