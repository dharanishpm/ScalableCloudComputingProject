# Real-Time E-commerce User Behaviour Analytics

 ## Features

- Real-time user activity tracking (page views, clicks, purchases)
- Live identification of trending products
- Product category performance analysis
- Advertisement Click-Through Rate (CTR) calculation
- Detection of sudden increases or decreases in product traffic
- User behaviour analytics and event monitoring
- Shopping cart abandonment detection
- Real-time dashboard with live metrics
- Historical analytics for long-term business insights
- Lambda Architecture integrating Batch Layer and Speed Layer
- Scalable cloud-based data processing
- Interactive data visualization using Streamlit
- Automated event processing and analytics
- Low-latency insights for business decision-makingately, while a streaming-only system cannot provide accurate historical analytics. Lambda Architecture combines both.

## Key Capabilities

- Process thousands of user events efficiently
- Provide low-latency analytics
- Combine historical and real-time data
- Detect trending products instantly
- Monitor advertisement performance
- Track customer engagement metrics
- Support scalable cloud deployment
- Generate business intelligence dashboards
